# 🛒 Amazon Clone (Frontend Only)

This is a frontend-only Amazon clone built using **HTML, CSS, and JavaScript**.  
It is a static project created for practice and learning web development concepts like layout design, styling, and responsive UI.

## 🚀 Features
- Amazon-like homepage design
- Navigation bar with search box
- Product sections with images, titles, and prices
- Add to cart button (UI only, no backend)
- Responsive design for desktop and mobile

## 🛠️ Technologies Used
- **HTML5** – structure of the website
- **CSS3** – styling and layout
- **JavaScript** – basic interactivity
